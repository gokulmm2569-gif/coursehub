# CourseHub BMAD Memlog

## Session decisions

- Approved CourseHub v1 product brief on 2026-08-19.
- Keep v1 local-first with no deployment or cloud storage.
- Use React + Django + Django REST Framework + MySQL.
- Use JWT access/refresh authentication with learner/admin role-based access.
- Use the React admin dashboard as the primary admin interface; retain Django admin only as a development shortcut.
- Support course search by title and description.
- Give every course one category and one reusable instructor profile.
- Allow free enrollment while displaying course prices without payment integration.
- Store images locally in Django media storage.
